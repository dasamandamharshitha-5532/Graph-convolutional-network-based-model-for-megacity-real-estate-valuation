# Graph-convolutional-network-based-model-for-megacity-real-estate-valuation
A GCN-based real estate valuation framework designed for megacities, where property prices are influenced by spatial proximity and neighborhood relationships. The model encodes real estate data as a graph structure and applies deep graph learning to enhance valuation performance.

## Current Implementation Status
- V1 (Deployed): Feature-based prediction using PyTorch + Django (rooms, floors, sqft)
- V2 (In Progress): Full GCN with spatial adjacency matrix using PyTorch Geometric for megacity graph
